# Security policy

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/bruce-shi/enigma/security/advisories/new).
Do not open a public issue for pairing-record exposure, arbitrary device commands,
local-vault compromise, updater-signature bypass, or release-signing problems.

Include the affected commit, platform, reproduction steps, impact, and a redacted
diagnostic export when useful. Never include real pairing records, device identifiers,
locations, Mapbox tokens, or private signing material.

Only the latest commit on `main` and the latest signed stable release receive security
fixes. No response-time guarantee or warranty is provided.
